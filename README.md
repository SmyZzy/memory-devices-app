# Запоминающие устройства ЭВМ

Компьютерное сопровождение дисциплины «Архитектура аппаратных средств» по теме «Запоминающие устройства ЭВМ»

**🌐 Сайт:** https://memory-devices-app.onrender.com

## Технологический стек

- **Backend:** Node.js + Express.js
- **База данных:** MySQL (Aiven Cloud)
- **Frontend:** HTML5, CSS3, JavaScript (vanilla)
- **Хостинг:** Render.com
- **Безопасность:** BCrypt хеширование паролей, сессии через express-session

## Системные требования (для локальной разработки)

- Node.js 18 или выше
- MySQL 8 или выше (или аккаунт Aiven)
- npm (идёт в комплекте с Node.js)

## Установка и запуск (локально)

### Шаг1: Установка зависимостей

Откройте терминал в папке проекта и выполните:

```bash
npm install
```

### Шаг2: Настройка подключения к базе данных

Для локальной разработки откройте файл `.env` и укажите данные MySQL:

```
DB_HOST=localhost
DB_USER=root
DB_PASSWORD=ваш_пароль
DB_NAME=memory_devices_db
DB_PORT=3306
```

Для работы с Aiven Cloud (как на продакшене):
```
DB_HOST=memory-db-memory-devices-app.h.aivencloud.com
DB_USER=avnadmin
DB_PASSWORD=AVNS_GsvqvTfofOObOLQCyXz
DB_NAME=defaultdb
DB_PORT=19732
```

### Шаг3: Создание и инициализация базы данных

```bash
npm run db:init
```

Скрипт автоматически:
- Создаст базу данных с кодировкой UTF8MB4
- Создаст все необходимые таблицы
- Заполнит данными (4 темы, тесты, группы, аккаунты)

### Шаг4: Запуск сервера

```bash
npm start
```

Сервер запустится на `http://localhost:3000`

### Шаг5: Открыть сайт

Откройте браузер и перейдите по адресу: `http://localhost:3000`

## Как настроить свой дизайн (фоны, изображения)

Все настраивается через один файл: `public/css/custom.css`

### Доступные переменные

| Переменная | Что меняет |
|-----------|------------|
| `--custom-body-bg` | Фон всей страницы |
| `--custom-navbar-bg` | Фон шапки сайта |
| `--custom-footer-bg` | Фон подвала |
| `--custom-table-bg` | Фон всех таблиц |
| `--custom-table-header-bg` | Фон шапок таблиц |
| `--custom-btn-primary-bg` | Фон основных кнопок |
| `--custom-btn-secondary-bg` | Фон вторичных кнопок |
| `--custom-card-bg` | Фон всех карточек |
| `--custom-hero-bg` | Фон hero-секции на главной |

Примеры:
```css
/* Сплошной цвет */
--custom-body-bg: #1a1a2e;

/* Градиент */
--custom-navbar-bg: linear-gradient(90deg, #667eea, #764ba2);

/* Изображение */
--custom-hero-bg: url('/images/hero-bg.jpg');
```

## Функционал

### Студент
- Просмотр теории по 4 темам с кнопками скачивания
- Прохождение мини-тестов (4 вопроса) после каждой темы
- Прохождение полного теста (30 вопросов, случайный порядок)
- Просмотр результатов тестирования
- Редактирование профиля (ФИО, пароль)

### Преподаватель
- Просмотр статистики тестирования всех студентов (фильтры, сортировка)
- Генерация аккаунтов для студентов по группам
- Удаление студентов
- Редактирование теории (название, содержание, файл лекции)
- Отдельные вкладки для редактирования мини-тестов и полных тестов
