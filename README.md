# Запоминающие устройства ЭВМ

Компьютерное сопровождение дисциплины «Архитектура аппаратных средств» по теме «Запоминающие устройства ЭВМ»

## Технологический стек

- **Backend:** Node.js + Express.js
- **База данных:** MySQL
- **Frontend:** HTML5, CSS3, JavaScript (vanilla)
- **Безопасность:** BCrypt хеширование паролей, сессии через express-session

## Системные требования

- Node.js 14 или выше
- MySQL 8 или выше (MySQL Workbench)
- npm (идёт в комплекте с Node.js)

## Установка и запуск

### Шаг 1: Установка зависимостей

Откройте терминал в папке проекта `memory-devices-app` и выполните:

```bash
npm install
```

### Шаг 2: Настройка подключения к базе данных

Откройте файл `.env` и укажите свои данные MySQL:

```
DB_HOST=localhost
DB_USER=root
DB_PASSWORD=123456
DB_NAME=memory_devices_db
DB_PORT=3306
```

Замените `DB_PASSWORD` на пароль вашего MySQL-сервера.

### Шаг 3: Создание и инициализация базы данных

Выполните скрипт инициализации:

```bash
npm run db:init
```

или

```bash
node database/init.js
```

Скрипт автоматически:
- Создаст базу данных `memory_devices_db`
- Создаст все необходимые таблицы
- Заполнит демо-данными (теории, тесты, группы, тестовые аккаунты)

### Шаг 4: Запуск сервера

```bash
npm start
```

или

```bash
node server.js
```

Сервер запустится на `http://localhost:3000`

### Шаг 5: Открыть сайт

Откройте браузер и перейдите по адресу:

```
http://localhost:3000
```

## Как настроить свой дизайн (фоны, изображения)

Все настраивается через один файл: `public/css/custom.css`

### Шаг 1: Добавить изображение

Положите файл изображения (JPG, PNG, WEBP) в папку `public/images/`

### Шаг 2: Отредактировать custom.css

Откройте файл `public/css/custom.css`. Найдите нужную строку и раскомментируйте её (уберите `/*` и `*/`):

```css
/* Фон всей страницы */
--custom-body-bg: url('/images/body-bg.jpg');

/* Фон шапки (navbar) */
--custom-navbar-bg: url('/images/navbar-bg.png');

/* Фон подвала (footer) */
--custom-footer-bg: url('/images/footer-bg.png');

/* Фон таблиц */
--custom-table-bg: url('/images/table-bg.png');

/* Фон заголовков таблиц */
--custom-table-header-bg: url('/images/table-header-bg.png');

/* Фон основных кнопок */
--custom-btn-primary-bg: url('/images/btn-bg.png');

/* Фон карточек (темы, формы, дашборд) */
--custom-card-bg: url('/images/card-bg.png');

/* Фон hero-блока на главной */
--custom-hero-bg: url('/images/hero-bg.png');
```

### Шаг 3: Перезагрузить страницу

Готово! Если путь к изображению НЕ указан — остаётся стандартный тёмный стиль.

### Доступные переменные

| Переменная | Что меняет |
|-----------|------------|
| `--custom-body-bg` | Фон всей страницы |
| `--custom-navbar-bg` | Фон шапки сайта |
| `--custom-footer-bg` | Фон подвала |
| `--custom-table-bg` | Фон всех таблиц |
| `--custom-table-header-bg` | Фон шапок таблиц |
| `--custom-btn-primary-bg` | Фон основных кнопок |
| `--custom-btn-secondary-bg` | Фон вторичных кнопок |
| `--custom-card-bg` | Фон всех карточек |
| `--custom-hero-bg` | Фон hero-секции на главной |

Можно использовать не только `url()`, но и любые CSS-значения: градиенты, цвета и т.д.

```css
/* Пример: сплошной цвет вместо изображения */
--custom-body-bg: #1a1a2e;

/* Пример: градиент */
--custom-navbar-bg: linear-gradient(90deg, #667eea, #764ba2);
```

## Как добавить файлы теории

1. Положите файл (PDF, DOCX и т.д.) в папку `public/files/`
2. Войдите в кабинет преподавателя
3. Перейдите во вкладку «Редактирование теории»
4. В поле «Путь к файлу» укажите: `/files/имя_вашего_файла.pdf`
5. Нажмите «Сохранить»

## Как добавить новых студентов

### Вариант 1: Через кабинет преподавателя

1. Войдите как `admin`
2. Перейдите во вкладку «Аккаунты»
3. Выберите группу, укажите количество, нажмите «Генерировать»
4. Скопируйте сгенерированные логины и пароли

### Вариант 2: Вручную через MySQL

```sql
INSERT INTO users (username, password, role, first_name, last_name, group_id)
VALUES ('новый_студент', '$2b$10$...хешированный_пароль...', 'student', 'Имя', 'Фамилия', 1);
```

## Функционал

### Студент
- Просмотр теории по 4 темам
- Прохождение мини-тестов после каждой темы
- Прохождение полного теста (30 вопросов, случайный порядок)
- Просмотр результатов тестирования
- Редактирование ФИО
- Смена пароля

### Преподаватель
- Просмотр статистики тестирования всех студентов
- Фильтрация по группе, сортировка по дате/баллам/группе
- Генерация аккаунтов для студентов
- Удаление студентов
- Редактирование теории (название, содержание, файлы)
- Редактирование вопросов тестов (добавление, изменение, удаление)

## Переустановка базы данных

Если нужно сбросить БД и создать заново:

```sql
DROP DATABASE memory_devices_db;
```

Затем снова выполните:

```bash
npm run db:init
```

## Поддержка

При проблемах с запуском проверьте:
1. MySQL запущен и доступен
2. Данные в `.env` корректны (логин, пароль)
3. Порт 3000 не занят другим приложением
4. Зависимости установлены (`npm install`)
