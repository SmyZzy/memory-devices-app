Привет! Эта инструкция поможет тебе развернуть сайт так, чтобы он работал
полноценно — с доменом, базой данных и был доступен из любой точки мира.

Весь процесс займёт около 30-40 минут. Следуй шагам по порядку.

ШАГ 3. ЗАГРУЗКА ФАЙЛОВ САЙТА В РЕПОЗИТОРИЙ
================================================================================

Ты получишь от разработчика ZIP-архив с папкой memory-devices-app.
Распакуй его в любое удобное место (например, на Рабочий стол).

3.1. Открой распакованную папку memory-devices-app
3.2. Удали папку node_modules (ЕСЛИ она есть) — она НЕ нужна в репозитории,
     так как весит слишком много. dependencies установятся автоматически.
3.3. Убедись что в папке есть эти файлы:
     - server.js
     - package.json
     - .env
     - папка public/
     - папка routes/
     - папка database/
3.4. Вернись в браузер на страницу своего репозитория на GitHub
3.5. На странице репозитория найди ссылку:
     «uploading an existing file» (она под текстом «...or create a new file»)
3.6. Перетащи ВСЕ файлы и папки из memory-devices-app в зону загрузки
     (или нажми «choose your files» и выбери всё)
3.7. Внизу в поле «Commit message» напиши: «Initial commit»
3.8. Нажми зелёную кнопку «Commit changes»

ГОТОВО. Все файлы сайта загружены в репозиторий.

Альтернативный способ (через GitHub Desktop, если файлов много):
  а) Скачай GitHub Desktop: https://desktop.github.com
  б) Установи и войди под своим аккаунтом GitHub
  в) File → Clone repository → выбери свой репозиторий
  г) Скопируй все файлы из memory-devices-app в папку репозитория на компьютере
  д) Удали node_modules (если есть)
  е) В GitHub Desktop: напиши «Initial commit» → нажми «Commit to main»
  ж) Нажми «Push origin»

================================================================================
ШАГ 4. РЕГИСТРАЦИЯ НА AIVEN.IO (для базы данных MySQL)
================================================================================

Aiven.io предоставляет бесплатный MySQL-сервер в облаке.

4.1. Открой сайт https://aiven.io
4.2. Нажми «Start for free» или «Sign up»
4.3. Зарегистрируйся через email или Google-аккаунт
4.4. Подтверди email (придёт письмо)
4.5. После входа нажми «Create service» (или «+ Create»)
4.6. Выбери «MySQL»
4.7. Настрой сервис:
     - Service name: memory-db (или любое имя)
     - Cloud provider: Google Cloud (или любой доступный бесплатный)
     - Region: выбери ближайший к тебе (например, Frankfurt, London)
     - Plan: выбери бесплатный (Free tier / Hobbyist)
     - Если нет бесплатного плана — выбери самый дешёвый (~$10/мес,
       но для студенческого проекта можно использовать бесплатный пробный период)
4.8. Нажми «Create service»
4.9. Дождись создания (может занять 5-10 минут, статус «Running»)

4.10. Когда сервис запущен, зайди в него и найди раздел
     «Connection information» или «Connection parameters».
     Тебе нужны эти данные:
       - Host (хост): например, memory-db-yourname.aivencloud.com
       - Port (порт): обычно 13306 или 3306
       - Username (имя пользователя): например, avnadmin
       - Password (пароль): будет показан один раз — СКОПИРУЙ ЕГО!
       - Database name (имя базы): обычно defaultdb

4.11. Также на странице сервиса найди вкладку «CA Certificate»
     и скачай файл ca.pem (сертификат). Он нужен для безопасного подключения.

ГОТОВО. У тебя есть облачная база данных MySQL.

================================================================================
ШАГ 5. ЗАПОЛНЕНИЕ БАЗЫ ДАННЫХ ДАННЫМИ
================================================================================

Ты получишь от разработчика SQL-файл с готовой базой данных
(например, backup_memory_devices.sql). Этот файл содержит ВСЕ данные:
темы, вопросы тестов, аккаунты пользователей и админа.

Способ 1 — через MySQL Workbench (рекомендуется):

5.1. Скачай MySQL Workbench: https://dev.mysql.com/downloads/workbench/
5.2. Установи и запусти
5.3. Нажми «+» рядом с «MySQL Connections»
5.4. Заполни подключение:
     - Connection Name: Aiven Memory DB (любое имя)
     - Connection Method: Standard TCP/IP over SSH (или Standard, если Aiven
       не требует SSH — проверь в панели Aiven)
     - Hostname: вставь Host из Шага 4.10
     - Port: вставь Port из Шага 4.10
     - Username: вставь Username из Шага 4.10
     - Password: нажми «Store in Vault...» и вставь пароль из Шага 4.10
5.5. Во вкладке «SSL» (если есть):
     - Use SSL: Required
     - SSL CA File: выбери скачанный файл ca.pem из Шага 4.11
5.6. Нажми «Test Connection» — должно написать «Successfully made the connection»
5.7. Нажми «OK» и подключись к базе (двойной клик по подключению)
5.8. В верхнем меню: File → Open SQL Script
5.9. Выбери файл backup_memory_devices.sql (или как он называется)
5.10. Нажми кнопку «⚡» (Execute) или Ctrl+Shift+Enter
5.11. Дождись выполнения. Внизу появится сообщение «... completed successfully»

Способ 2 — через командную строку (если установлен MySQL клиент):

  mysql -h <HOST> -P <PORT> -u <USERNAME> -p --ssl-ca=ca.pem < backup_memory_devices.sql

  Вместо <HOST>, <PORT>, <USERNAME> подставь данные из Шага 4.10.
  Система попросит ввести пароль — вставь пароль из Шага 4.10.

ГОТОВО. База данных заполнена. Все темы, тесты и аккаунты загружены.

ШАГ 7. РАЗВЁРТЫВАНИЕ САЙТА НА RENDER
================================================================================

7.1. Войди на https://render.com/dashboard
7.2. Нажми «New +» → «Web Service»
7.3. Выбери свой репозиторий (memory-devices-app)
     - Если репозиторий не отображается, нажми «Configure account»
       и разреши доступ к нужному репозиторию
7.4. Заполни настройки:
     - Name: memory-devices-app (или любое имя)
     - Region: Frankfurt (Германия) — ближайший к России
     - Branch: main
     - Root Directory: (оставь пустым, если файлы в корне репозитория)
     - Runtime: Node
     - Build Command: npm install
     - Start Command: node server.js
     - Instance Type: Free (бесплатный тариф)
7.5. Нажми «Advanced» и добавь переменные окружения (Environment Variables):

     Ключ (KEY):              Значение (VALUE):
     ─────────────────────    ───────────────────────────────────
     PORT                     3000 (или оставь как есть)
     SESSION_SECRET           придумай любой длинный случайный текст
                              (например: mySecretKey2025RandomText!)
     DB_HOST                  Host из Шага 4.10 (например:
                              memory-db-yourname.aivencloud.com)
     DB_PORT                  Port из Шага 4.10 (например: 13306)
     DB_USER                  Username из Шага 4.10 (например: avnadmin)
     DB_PASSWORD              Password из Шага 4.10
     DB_NAME                  Database name из Шага 4.10 (например: defaultdb)

7.6. Нажми «Create Web Service»
7.7. Дождись сборки и запуска (5-10 минут). Статус изменится на «Live»
7.8. Когда сервис запущен, ты увидишь URL вида:
     https://memory-devices-app-xxxxx.onrender.com

ЭТО И ЕСТЬ ТВОЙ САЙТ! Он уже работает в интернете.

================================================================================
ШАГ 8. НАСТРОЙКА ДОМЕНА (опционально, но рекомендуется)
================================================================================

Если ты хочешь свой красивый домен (например, memory-devices.ru):

8.1. Купи домен у любого регистратора:
     - https://reg.ru
     - https://nic.ru
     - https://namecheap.com (для .com/.net)
     Цена: от 200 руб/год за .ru

8.2. После покупки домена зайди в панель управления регистратора
8.3. Найди раздел «DNS» или «Управление DNS-записями»
8.4. Добавь CNAME-запись:
     - Тип записи: CNAME
     - Имя (Host): www (или @ для основного домена)
     - Значение (Value): memory-devices-app-xxxxx.onrender.com
       (твой URL из Шага 7.8)
     - TTL: автоматический или 3600

8.5. Вернись в Render:
     - Зайди в свой сервис → Settings → Custom Domains
     - Нажми «Add Custom Domain»
     - Введи свой домен (например, www.memory-devices.ru)
     - Нажми «Add Domain»
     - Render проверит DNS-запись. Это может занять от 5 минут до 24 часов

8.6. Когда DNS обновится, статус станет «Verified»

ГОТОВО. Сайт доступен по твоему домену!

Важно: на бесплатном тарифе Render SSL-сертификат для кастомного домена
создаётся автоматически. HTTPS будет работать.

ВОЗМОЖНЫЕ ПРОБЛЕМЫ И РЕШЕНИЯ
================================================================================

Проблема: Render показывает «Build failed»
Решение: Проверь что package.json существует и в нём есть
         "dependencies": { "express": "...", "mysql2": "...", ... }
         Проверь что Build Command: npm install

Проблема: Сайт не подключается к базе данных
Решение: Проверь переменные окружения в Render (Settings → Environment):
         - DB_HOST должен совпадать с Host из Aiven
         - DB_PORT должен быть правильным (не 3306, а например 13306)
         - DB_USER и DB_PASSWORD должны совпадать
         - В Aiven убедись что сервис в статусе «Running»

Проблема: На сайте «кракозябры» вместо русского текста
Решение: В .env файле добавь: DB_CHARSET=utf8mb4
         В pool.js убедись что charset: 'utf8mb4'

Проблема: DNS-запись домена не подтверждается
Решение: Подожди до 24 часов. DNS обновляется не мгновенно.
         Проверь запись через https://dnschecker.org

Проблема: Бесплатный тариф Render «засыпает»
Решение: Это нормально. При первом обращении после простоя сайт загружается
         30-60 секунд. Для бесплатного тарифа это ограничение Render.
         Можно использовать сервисы вроде UptimeRobot (бесплатно) для
         периодического «пинга» сайта, чтобы он не засыпал.
