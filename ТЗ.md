# Техническое задание (ТЗ)
## Система компьютерного сопровождения дисциплины «Архитектура аппаратных средств» по теме «Запоминающие устройства ЭВМ»

---

## 1. Общие сведения

**Название системы:** Запоминающие устройства ЭВМ  
**Назначение:** Компьютерное сопровождение дисциплины «Архитектура аппаратных средств»  
**Целевая аудитория:** Студенты и преподаватели технических специальностей  
**Версия:** 1.0  
**Дата:** 04.05.2026  

---

## 2. Цели и задачи

### Цели:
1. Обеспечить доступ к учебным материалам по теме «Запоминающие устройства ЭВМ»
2. Автоматизировать проверку знаний студентов через тестирование
3. Предоставить преподавателю инструменты для управления курсом

### Задачи:
- Систематизация теоретического материала по 4 темам
- Создание системы тестирования (мини-тесты и полные тесты)
- Разработка панели управления для преподавателя
- Обеспечение безопасности данных (хеширование паролей, сессии)

---

## 3. Функциональные требования

### 3.1. Роль «Студент»

| Функция | Описание |
|---------|----------|
| Просмотр теории | Доступ к 4 темам с лекциями в формате PPT/DOCX |
| Мини-тесты | 4 вопроса после каждой темы, мгновенный результат |
| Полный тест | 30 случайных вопросов из банка (темы 1-4) |
| Личный кабинет | Просмотр своих результатов, редактирование ФИО, смена пароля |
| Скачивание | Возможность скачать лекцию по каждой теме |

### 3.2. Роль «Преподаватель»

| Функция | Описание |
|---------|----------|
| Статистика | Просмотр результатов всех студентов с фильтрами и сортировкой |
| Генерация аккаунтов | Массовое создание логинов/паролей для студентов по группам |
| Управление студентами | Удаление студенческих аккаунтов |
| Редактирование теории | Изменение названий тем, содержания, прикрепление файлов лекций |
| Редактирование мини-тестов | Добавление, изменение, удаление вопросов для конкретных тем |
| Редактирование полных тестов | Управление банком вопросов для итогового тестирования |
| Редактирование профиля | Изменение ФИО преподавателя |

---

## 4. Технические требования

### 4.1. Технологический стек

| Компонент | Технология |
|-----------|-------------|
| Backend | Node.js + Express.js |
| База данных | MySQL 8.0+ (развернута в Aiven Cloud) |
| Frontend | HTML5, CSS3, JavaScript (Vanilla) |
| Хостинг | Render.com |
| Безопасность | BCrypt (хеширование), express-session (сессии) |
| Кодировка БД | UTF8MB4 (поддержка русского языка) |

### 4.2. Системные требования

**Серверная часть (Render.com):**
- Node.js 18+
- ОЗУ: 512 МБ (минимум)
- Диск: 1 ГБ
- MySQL (Aiven): порт 19732, SSL-соединение

**Клиентская часть:**
- Браузер: Chrome, Firefox, Edge (последние версии)
- JavaScript: включен
- Экран: от 320px (мобильная), рекомендуется 1920px

## 5. Структура данных

### 5.1. Таблицы базы данных

Подробное описание каждой таблицы приведено в файле **«ОПИСАНИЕ_БАЗЫ_ДАННЫХ.md»**.

**Краткая структура:**

1) **Таблица «groups»** — справочник учебных групп (ИС-101, ИС-102 и т.д.)
2) **Таблица «users»** — учётные записи пользователей (студенты и преподаватели) с хешированными паролями
3) **Таблица «theory_topics»** — темы теоретического материала (4 темы с HTML-содержанием и файлами лекций)
4) **Таблица «mini_tests»** — вопросы мини-тестов по каждой теме (4 вопроса на тему, варианты A/B/C/D, правильный ответ)
5) **Таблица «full_tests»** — общий банк вопросов для итогового тестирования (30 случайных вопросов из банка)
6) **Таблица «test_results»** — результаты тестирования студентов (связь с users, темами, тип теста, баллы, проценты, даты начала и завершения)

## 7. Интерфейс пользователя

### 7.1. Студент
- Главная страница: список 4 тем с кнопками «Изучить тему» и «Скачать лекцию»
- Страница темы: теоретический материал + мини-тест (4 вопроса)
- Полный тест: 30 случайных вопросов из всех тем
- Личный кабинет: статистика, настройки профиля

### 7.2. Преподаватель
- Дашборд с ФИО и кнопкой редактирования профиля
- Вкладка «Статистика»: таблица результатов с фильтрами
- Вкладка «Аккаунты»: генерация и управление студентами
- Вкладка «Редактирование теории»: список тем с полями редактирования
- Вкладка «Редактирование мини-тестов»: отдельная вкладка для вопросов по темам
- Вкладка «Редактирование полных тестов»: отдельная вкладка для общего теста

---

## 8. Безопасность

1. **Пароли:** Хеширование через BCrypt (salt rounds = 10)
2. **Сессии:** express-session, время жизни — 24 часа
3. **Доступ:** Проверка ролей на сервере (middleware checkTeacher)
4. **SQL-инъекции:** Использование параметризованных запросов (pool.query)
5. **База данных:** SSL-соединение с Aiven Cloud, доступ только с разрешенных IP

## 11. Сопровождение

### 11.1. Обновление лекций
1. Загрузить файл в `public/files/`
2. Войти как преподаватель
3. Вкладка «Редактирование теории»
4. Указать новый путь к файлу: `/files/имя_файла.ppt`

### 11.2. Добавление вопросов
- Мини-тесты: выбрать тему, заполнить форму, нажать «Добавить»
- Полные тесты: заполнить форму, нажать «Добавить»
