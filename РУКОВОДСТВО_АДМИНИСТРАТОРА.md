- **Все группы / Выбор конкретной группы** — фильтрация по учебной группе

## 5. Вкладка «Аккаунты»

### 5.1. Генерация аккаунтов для студентов

**Алгоритм действий:**
1. Выберите группу из выпадающего списка
2. Укажите количество аккаунтов (от 1 до 100)
3. Введите префикс для логинов (по умолчанию: `stud`)
4. Нажмите «Генерировать»

**Результат:**
- Создаются указанное количество аккаунтов
- Логины формируются по шаблону: `префикс_название_группы_случайный_код`
- Пароли генерируются автоматически (случайные 8-значные коды)
- Таблица со списком логинов и паролей появляется под формой
- Кнопка «Копировать все» — копирует логины и пароли в буфер обмена

### 5.2. Список студентов

Таблица со всеми зарегистрированными студентами:
| Столбец | Описание |
|---------|----------|
| Логин | Имя пользователя для входа |
| ФИО | Фамилия, имя, отчество |
| Группа | Учебная группа |
| Действие | Кнопка «Удалить» |

**Удаление студента:**
1. Нажмите «Удалить» напротив нужного студента
2. Подтвердите действие в появившемся окне
3. Студент и его результаты будут удалены из системы

## 6. Вкладка «Редактирование теории»

Позволяет управлять содержанием теоретических материалов по 4 темам.

### Доступные темы:
1. Тема 1. Оперативная память
2. Тема 2. Кеш-память
3. Тема 3. Накопители
4. Тема 4. Системы RAID

### Редактирование темы:
Для каждой темы доступны поля:
- **Название темы** — заголовок (например: «Тема 1. Оперативная память»)
- **Содержание (кратко)** — HTML-текст, отображаемый на странице темы
- **Путь к файлу** — путь к лекции (например: `/files/theme1_memory.docx`)

**Сохранение:**
1. Внесите изменения в нужные поля
2. Нажмите кнопку «Сохранить» напротив темы
3. Появится уведомление «Сохранено»

### Как прикрепить новый файл лекции:
1. Загрузите файл (PDF, PPT, DOCX, DOC) в папку `public/files/` проекта
2. В поле «Путь к файлу» укажите: `/files/имя_файла.расширение`
3. Нажмите «Сохранить»

## 7. Вкладка «Редактирование мини-тестов»

Мини-тесты привязаны к конкретным темам (по 4 вопроса на тему).

### Просмотр вопросов:
- Вопросы отображаются в виде блоков с указанием темы
- Для каждого вопроса видны: текст вопроса и варианты ответов (A, B, C, D)

### Редактирование вопроса:
1. Выберите тему из выпадающего списка (если нужно переместить вопрос в другую тему)
2. Отредактируйте текст вопроса
3. Отредактируйте варианты ответов (A, B, C, D)
4. Выберите правильный ответ из выпадающего списка (OK)
5. Нажмите «Сохранить»

### Удаление вопроса:
1. Нажмите кнопку «Удалить» напротив вопроса
2. Подтвердите действие

### Добавление нового вопроса мини-теста:
1. Выберите тему из выпадающего списка
2. Введите текст вопроса
3. Заполните варианты ответов (A, B, C, D)
4. Выберите правильный вариант (OK)

### Основные SQL-запросы:

**Посмотреть всех студентов:**
```sql
SELECT u.id, u.username, u.first_name, u.last_name, g.name as group_name
FROM users u
LEFT JOIN `groups` g ON u.group_id = g.id
WHERE u.role = 'student';
```

**Удалить студента:**
```sql
DELETE FROM users WHERE id = 'ID_СТУДЕНТА';
```

**Посмотреть результаты тестирования:**
```sql
SELECT tr.*, u.first_name, u.last_name, g.name as group_name
FROM test_results tr
JOIN users u ON tr.user_id = u.id
LEFT JOIN `groups` g ON u.group_id = g.id
ORDER BY tr.completed_at DESC;
```

**Добавить вопрос в полный тест:**

## 11. Часто возникающие проблемы

### Проблема: Студенты не могут войти
**Решение:**
1. Проверьте, существует ли аккаунт в таблице `users`
2. Убедитесь, что роль — `student`
3. Если забыли пароль — удалите студента и сгенерируйте новый аккаунт

### Проблема: Сайт не открывается
**Решение:**
1. Проверьте статус на Render: https://dashboard.render.com/web/srv-d7rrs5tckfvc73a9mq1g
2. Если сервис упал — нажмите «Manual Deploy»
3. Проверьте, не истек ли срок действия сертификата Aiven

### Проблема: Не сохраняются изменения в теории
**Решение:**
1. Проверьте, заполнены ли все поля (название обязательно)
2. Откройте консоль браузера (F12) — посмотрите ошибки в вкладке Console
3. Проверьте работу API через вкладку Network
