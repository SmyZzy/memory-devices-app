1. ЧТО ЭТО ЗА СИСТЕМА
--------------------------------------------------------------------------------
Это веб-приложение — компьютерное сопровождение дисциплины для студентов и
преподавателей. Система позволяет изучать теорию по запоминающим устройствам
ЭВМ, проходить мини-тесты после каждой темы, сдавать полное тестирование
и отслеживать результаты.

2. КАК ОТКРЫТЬ САЙТ
--------------------------------------------------------------------------------
1. Откройте браузер (Chrome, Firefox, Edge, Яндекс.Браузер)
2. Введите адрес: http://localhost:3000
   (или IP-адрес сервера, если сайт работает на другом компьютере)
3. Если вы видите главную страницу — система работает

3. НАВИГАЦИЯ ПО САЙТУ
--------------------------------------------------------------------------------

[ Главная страница ]
├── Вверху — шапка сайта с логотипом «ЗУ ЭВМ» и меню навигации
├── В центре — название дисциплины и два больших блока:
│   ├── «Изучить теорию» — переход к темам
│   └── «Пройти тест» — переход к полному тестированию
├── Внизу — три карточки с описанием разделов
└── В правом верхнем углу:
    ├── «Войти» — если вы не авторизованы
    └── ФИО + «Кабинет» + «Выйти» — если вы вошли

[ Страница входа (login.html) ]
├── Введите логин и пароль
├── Пароль — минимум 8 символов
├── Нажмите «Войти»
└── Если нет аккаунта — нажмите «Зарегистрироваться»

[ Страница регистрации (register.html) ]
├── Заполните: фамилия, имя, отчество (необязательно)
├── Придумайте логин
├── Придумайте пароль (мин. 8 символов)
├── Подтвердите пароль
├── Выберите группу (необязательно)
└── Нажмите «Зарегистрироваться» → переадресация на вход

[ Теория (theory.html) ]
├── Список всех 4 тем
├── Нажмите «Изучить тему» → переход к конкретной теме
└── Внизу каждой темы — мини-тест для самопроверки

[ Детальная страница темы (theory-detail.html) ]
├── Название темы
├── Краткое содержание теории (текст с заголовками и списками)
├── Ссылка на файл с полным текстом (если преподаватель прикрепил)
├── Мини-тест после теории:
│   ├── 4 вопроса с вариантами A, B, C, D
│   ├── Выберите ответ и нажмите «Отправить»
│   └── Результат: процент правильных + оценка
└── Кнопка «← К списку тем» — возврат к списку

[ Тестирование (test.html) ]
├── 30 вопросов по всем темам в случайном порядке
├── Каждый вопрос — 4 варианта ответа
├── Кнопка «Завершить тест» — в конце страницы
├── Если не авторизованы — предупреждение сверху
│   └── Результаты НЕ будут сохранены без входа
└── Результат: балл, процент, оценка

[ Кабинет студента (student.html) ]
├── Блок «Мои данные» — ФИО, логин, группа, дата регистрации
├── Кнопка «Редактировать» — изменить ФИО
├── Блок «Смена пароля» — текущий + новый пароль
└── Таблица результатов — все пройденные тесты с баллами

[ Кабинет преподавателя (teacher.html) ]
├── Блок «Мои данные» — ФИО, логин
├── Вкладка «Статистика»:
│   ├── Таблица результатов всех студентов
│   ├── Фильтр по группе
│   ├── Сортировка: по дате / по баллам / по группе / по результату
│   └── Порядок: по возрастанию / убыванию
├── Вкладка «Аккаунты»:
│   ├── Генерация аккаунтов (выбрать группу + количество)
│   ├── Сгенерированные логины и пароли
│   └── Список студентов с кнопкой «Удалить»
├── Вкладка «Редактирование теории»:
│   ├── Изменение названия, содержания, пути к файлу
│   └── Кнопка «Сохранить» у каждой темы
└── Вкладка «Редактирование тестов»:
    ├── Список всех вопросов с полями для редактирования
    ├── Метки A, B, C, D у вариантов ответа
    ├── Выбор правильного ответа (OK)
    ├── Кнопки «Сохранить» и «Удалить»
    └── Форма добавления нового вопроса

5. КАК ДОБАВИТЬ ФАЙЛ ТЕОРИИ
--------------------------------------------------------------------------------
1. Поместите файл (PDF, DOCX, и т.д.) в папку: public/files/
2. Войдите как преподаватель
3. Вкладка «Редактирование теории»
4. В поле «Путь к файлу» укажите: /files/имя_файла.pdf
5. Нажмите «Сохранить»

6. КАК ПОСТАВИТЬ СВОЙ ФОН НА САЙТЕ
--------------------------------------------------------------------------------
1. Поместите изображение в папку: public/images/
2. Откройте файл: public/css/custom.css
3. Найдите нужный блок, раскомментируйте (уберите /* и */)
4. Замените путь на свой
5. Сохраните файл, обновите страницу (Ctrl+Shift+R)

Доступные элементы для кастомизации:
  - Фон всей страницы
  - Фон шапки сайта
  - Фон подвала
  - Фон таблиц
  - Фон заголовков таблиц
  - Фон основных кнопок
  - Фон вторичных кнопок
  - Фон всех карточек
  - Фон hero-секции на главной

7. ЧАСТО ЗАДАВАЕМЫЕ ВОПРОСЫ
--------------------------------------------------------------------------------
Q: Нужно ли входить в аккаунт для прохождения теста?
A: Нет, тест можно пройти без входа. Но результаты НЕ сохранятся.

Q: Как сменить пароль?
A: Зайдите в личный кабинет студента → блок «Смена пароля».

Q: Преподаватель может редактировать вопросы?
A: Да, во вкладке «Редактирование тестов» в кабинете преподавателя.

Q: Как создать аккаунты для целой группы?
A: В кабинете преподавателя → вкладка «Аккаунты» → «Генерация аккаунтов».

Q: Сайт показывает белый фон вместо тёмного?
A: Нажмите Ctrl+Shift+R для сброса кэша браузера.
